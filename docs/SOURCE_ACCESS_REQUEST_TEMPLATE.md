# Request for authorized healthcare directory access

Subject: Request for Authorized Access to Public Healthcare Directory Data for Arogio

We are developing Arogio, a local healthcare directory using publicly available professional and facility information. We will not collect patient data, medical histories, prescriptions, appointments, or insurance claims.

Please confirm:

1. Official landing page and documentation URL.
2. Organization owner and technical contact.
3. Whether the directory is intentionally public.
4. Public CSV, JSON, XML, PDF, or documented API availability.
5. Request method, parameters, pagination, and sample response/schema.
6. Allowed request frequency, timeout, and concurrency.
7. Whether automated retrieval is permitted.
8. Whether local storage and redistribution/display are permitted.
9. Attribution text and retention restrictions.
10. Source update frequency and effective/expiry fields.
11. Stable source record identifiers.
12. Fields supplied, including facility name, address, city, state, pincode, phone, coordinates, specialties, doctor name, qualification, registration number, and relationships.
13. Whether written approval is required for periodic synchronization.
